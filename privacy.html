隱私權政策

更新日期 2026-11-23

本政策適用於由 shadow11190 維護的 Galaxy Box Android App（dev.galaxy.toolbox）及本介紹網站。App 的診斷與監控主要在裝置上處理。App 無須註冊帳號，未內建廣告、使用行為分析或自動當機回報服務。

裝置上的資料與權限

  • 硬體與電池。App 讀取 Android 或裝置提供的型號、硬體規格、溫度、電池及其他診斷數據，用於顯示裝置狀態、測試結果和桌面小工具。
  • 藍牙與 App 用量。配件功能可在獲得權限後讀取已連線裝置資訊，例如名稱、電量及可取得的音訊編解碼資訊。用量分析在您開啟 Android 的使用情況存取後，於裝置上處理應用程式用量及系統提供的流量統計。
  • 相機、麥克風與定位。使用相關功能並授權時，App 會讀取相機資訊、在測試畫面預覽相機、取樣麥克風以量測訊號，或讀取定位以測試精度。測試預覽、音訊樣本及定位測試結果在裝置上處理，App 不會將它們上傳至開發者。
  • 生物辨識。由 Android 執行驗證。App 取得系統回報的驗證狀態。
  • Shizuku、通知與浮動監控。您可另行授權 Shizuku 以讀取支援的電池或 GPU 診斷資料。開啟通知或浮動監控時，裝置狀態可顯示在系統通知、鎖定畫面或其他 App 上方，視您的設定而定。

外部連線及分享

查詢 Samsung 公開韌體時，App 會直接向 Samsung 來源發送 HTTPS 請求。請求路徑含型號及地區代碼（CSC），接收端也可取得連線 IP 位址。開啟 GitHub、Coolapk、Shizuku 或其他外部連結後，該服務依其政策處理造訪資料。

自行匯出診斷報告或複製摘要時，資料會寫入您選擇的位置或系統剪貼簿。若您選擇雲端儲存位置、分享匯出檔案，或在 GitHub 提交內容，相關服務或接收者會取得您提供的資料。

儲存、保留與刪除

App 將偏好設定、匯入的背景圖片、充電測試紀錄等資料保存在裝置上。您可以在 App 刪除背景或清除測試紀錄，也可到 Android 設定清除 Galaxy Box 的儲存空間或解除安裝。已匯出的檔案與分享出去的內容，請在原儲存位置或接收服務另行管理。

您可以在 Android 設定撤回 App 權限、使用情況存取或浮動視窗權限，也可以在 Shizuku 解除授權。撤回權限後，使用該權限的功能可能受限。

本網站

網站的頁面、圖片與預覽程式由 GitHub Pages 提供。Galaxy Box 網站本身未加入分析、廣告、表單或追蹤 Cookie。GitHub 作為託管商，可能依其政策處理 IP 位址與請求等連線資料。
