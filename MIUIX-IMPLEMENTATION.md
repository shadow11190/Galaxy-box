# MIUIX style integration

Galaxy box keeps its original interface and offers an optional MIUIX style under **Overview → Display effects**. The liquid-glass switch remains independent of the style selector. The MIUIX components are from the community-maintained [compose-miuix-ui/miuix v0.9.4](https://github.com/compose-miuix-ui/miuix/tree/v0.9.4), not an official Xiaomi SDK.

The MIUIX path uses `MiuixTheme` and `ThemeController`, with System, Light, Dark, and Android 12+ Monet choices. The page background and card surfaces retain gray tonal separation even with dynamic color. The page shell uses MIUIX `Scaffold` and a collapsing `TopAppBar` connected to the content's nested scroll. Original mode keeps its own header and navigation layout. Both styles keep the existing Backdrop glass capture and data sources.

Reusable bridges route text, buttons, choices, switches, sliders, inputs, progress, separators, and detail sheets to MIUIX controls only when that style is selected. `InfoCard` and About sections use MIUIX grouped cards. Settings rows use `SwitchPreference`. A path-backed squircle, using Miuix's public `Path.addSquircleRect`, provides smooth corners even on Android versions below the shader-backed modifier's support level. The home-screen widgets remain Android RemoteViews and are not Compose/MIUIX widgets.

Pinned Android dependencies: `miuix-ui-android`, `miuix-preference-android`, `miuix-squircle-android`, and `miuix-icons-android`, all at 0.9.4. This release requires Android API 37 for compilation and Android Gradle Plugin 9.1.1 / Gradle 9.3.1; `minSdk` remains 26 and `targetSdk` remains 35. The original style retains Material components for its established appearance. See `THIRD_PARTY_NOTICES.md` and the bundled Apache 2.0 licence.

Validation on 2026-10-24: `testDebugUnitTest` passed all 288 tests; `lintDebug` finished with 0 errors and 20 warnings; `assembleDebug`, `assembleDebugAndroidTest`, and R8-enabled `assembleRelease` succeeded. Robolectric produced light/dark preview bitmaps for both styles using the MIUIX path-backed card fallback because its native renderer cannot parse the MIUIX AGSL shader. Visual checks still require a device or emulator: switch styles at runtime; inspect the five tabs in light/dark/Monet and enlarged text; scroll each list to verify title collapse; open and dismiss About and sensor detail sheets; turn glass on/off and inspect card contrast and edge-to-edge insets; rotate and repeat with the navigation bar and gesture navigation.
